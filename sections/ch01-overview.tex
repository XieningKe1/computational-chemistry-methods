\subsection{从多体薛定谔方程到四类方法}
\label{ch:01:sec:four-families}

化学问题最终都归结为一个固定原子核构型下的电子方程。分子中 $N$ 个电子，每个电子带三个空间坐标和一个自旋坐标，精确波函数 $\Psi$ 因此是一个 $4N$ 元函数。把它写下来已经昂贵，把它精确解出来更昂贵：维度随电子数指数增长。整个计算化学的历史，就是寻找"在给定精度目标下把成本压到可接受"的不同近似路径\citep{szabo1996,jensen2017}。

这些路径被组织成四大家族：

\begin{enumerate}
  \item \textbf{波函数方法}（wavefunction-based）：显式写出并求解多电子波函数 $\Psi$。从平均场近似（Hartree--Fock，HF）开始，逐级加入电子相关：MP2（二阶微扰）、CI（组态相互作用）、CC（耦合簇），再到处理强静态相关的多参考路线 CASSCF、CASPT2/NEVPT2、MRCI\citep{szabo1996,helgaker2000}。
  \item \textbf{密度泛函理论}（density-functional theory，DFT）：放弃 $4N$ 元波函数，改用只有三个空间坐标的电子密度 $\rho(\mathbf{r})$。Kohn--Sham 方程把问题重新变回类单电子方程，代价是交换相关泛函 $E_\xc$ 必须近似\citep{parr1989}。
  \item \textbf{半经验方法 / 紧束缚}（semiempirical / tight-binding）：保留电子和轨道图像，但把大量双电子积分参数化、只处理价电子。GFN2-xTB 是本书代表，它带自洽电荷（SCC）\citep{bannwarth2019gfn2}。
  \item \textbf{分子力场}（force field）：彻底去掉电子，用经典势能面描述原子间相互作用——键伸缩、角弯曲、二面角（键合项）加上 Lennard-Jones 与库仑（非键合项）。GFN-FF、UFF、AMBER、CHARMM、OPLS-AA 都属于这一类\citep{spicher2020gfnff,rappe1992uff,cornell1995amber,jorgensen1996oplsaa}。
\end{enumerate}

四大家族的关系不是"谁替代谁"，而是"覆盖不同的规模与精度需求"。图~\ref{ch:01:fig:map} 把全书方法排成四条泳道：波函数单参考路线（HF、MP2、CISD、CCSD(T)）、多参考分支（CASSCF、CASPT2/NEVPT2/MRCI）、密度泛函雅各布天梯（KS-DFT、LDA、GGA、meta-GGA、杂化、双杂化）以及半经验\,/\,力场（GFN2-xTB、GFN-FF）。同一条泳道内向右一级，就对应问题链中的一次"修复"——箭头上的文字正是该方法多解决的问题；唯一的跨泳道分岔是 HF 到 CASSCF 的虚线箭头：单参考假设在强静态相关下失效，必须转入活性空间。方框第二行给出章号与成本标度，这张地图因此同时是后续每一章的坐标。

\subsection{精度—成本—相关类型}
\label{ch:01:sec:three-axes}

比较方法时不要只看一个数字。任何方法都可以放在三个轴上衡量：

\begin{itemize}
  \item \textbf{精度}（accuracy）：相对于参考值的误差，例如 CH$_4$ 相对 CCSD(T)/def2-TZVPP 的能量偏差。
  \item \textbf{成本}（cost）：随体系规模 $N$ 的标度 $\mathcal{O}(N^n)$，以及常数因子与内存需求。
  \item \textbf{相关类型}（correlation type）：方法主要处理动态相关（dynamic correlation，电子瞬时回避）还是静态相关（static/nondynamic correlation，近简并组态），或者两者都处理。
\end{itemize}

"更贵"并不自动等于"更适合所问的问题"。例如 CASSCF 处理 CH$_4$ 这种弱静态相关体系时，能量可能反而比便宜的 MP2 更差（见第 7 章），因为它的活性空间选择与轨道优化是为强静态相关设计的；反之，单参考的 CCSD(T) 在拉伸键、过渡金属多组态问题上会失效，而它在平衡构型附近几乎是金标准。选择方法的正确提法是："这个问题需要的相关类型是哪种？在此类型下，我的精度预算是多少？"三轴的交叉决定了 \S\ref{ch:01:sec:method-table} 表格中每一个方法的存在理由，也决定了第 16 章决策树的走向。

\subsection{CH$_4$ 与 H$_2^-$ 算例协议}
\label{ch:01:sec:protocols}

全书用两个贯穿始终的算例把不同方法放到同一精度标尺上，所有数值只来自 \texttt{data/*.csv}。

\textbf{CH$_4$ 单点}：采用 $T_d$ 对称构型，$r(\mathrm{C\!-\!H}) = 1.087$\,\AA（坐标块取 $a = 0.6276$\,\AA），电荷 0、多重度 1。20 个方法中，16 个用 def2-TZVPP；B97-3c 与 r$^2$SCAN-3c 使用各自内置基组（def2-mTZVP / def2-mTZVPP）；GFN2-xTB 与 GFN-FF 不含外部基组。参考值为 CCSD(T)/def2-TZVPP $E = -40.438598$\,Eh。能量与 $\Delta E$ 见 \texttt{data/ch4\_results.csv}。

\textbf{H$_2^-$ 势能曲线}：6 个方法（UHF、MP2、CCSD(T)、CASSCF、NEVPT2、MRCI）各扫 8 个核间距 $R = 0.6$–$3.0$\,\AA（$0.6$–$1.2$ 步长 0.2，随后 $1.5$，之后 $2.0$–$3.0$ 步长 0.5），全部 $n_{\mathrm{roots}} = 1$，活性空间 CAS(3,2)。数据见 \texttt{data/h2m\_pes.csv}。CH$_4$ 检验"同一分子、不同方法"的能量标尺，H$_2^-$ 检验"同一方法、不同键长"的行为差异，两者共同支撑第 16 章的决策树。

\subsection{三种阅读路线}
\label{ch:01:sec:routes}

本书有 16 章，不必线性读完。三条推荐路线：

\begin{enumerate}
  \item \textbf{波函数优先}：第 2 章奠基后，依次读第 3--8 章（HF$\to$MP2$\to$CI$\to$CC$\to$CASSCF$\to$多参考），把 DFT 部分（第 9--13 章）作为对照阅读。适合想理解"相关能怎么被逐级补全"的读者。
  \item \textbf{DFT 优先}：第 2 章后直接进入第 9 章，再沿雅各布天梯读第 10--13 章，最后回看第 3--8 章作为波函数参照。适合以泛函应用为主的读者。
  \item \textbf{实用决策优先}：先读本章表~\ref{ch:01:tab:methods} 与第 16 章决策树，再按手上问题按需跳读具体章节（如弱相互作用读第 12 章，强静态相关读第 7--8 章，大规模筛选读第 14--15 章）。
\end{enumerate}

三条路线共享同一套符号（CONTRACT §1）与同一批算例，交叉阅读不会失去坐标。

% ---- 5. 常见陷阱 ----
\begin{pitfall}
\begin{itemize}
  \item \textbf{把成本当作精度}：$\mathcal{O}(N^7)$ 的 CCSD(T) 并非对任何问题都优于便宜方法；强静态相关体系（拉伸键、双自由基）会让单参考方法系统性失败。
  \item \textbf{跨方法直接比较总能量}：不同方法（尤其 GFN2-xTB 与 GFN-FF）的绝对总能量不在同一标尺上，只能比"相对参考的 $\Delta E$"。
  \item \textbf{把方法地图当等级表}：波函数路线与 DFT 路线不是同一条阶梯，二者在成本—精度平面上各有覆盖区间。
\end{itemize}
\end{pitfall}

% ---- 6. 小结 + 过渡 ----
\subsection*{小结}
本章建立了全书的方法地图：四大家族（波函数方法、DFT、半经验、力场）、三根评价轴（精度、成本、相关类型），以及 17 行方法存在意义表~\ref{ch:01:tab:methods} 与两个贯穿算例的协议。所有后续章节都在回答"这个方法比上一级多解决了什么"，并共享同一套符号与算例。地图的第一站是一个看似根本的障碍：为什么多体薛定谔方程不能直接解？带着这个问题，我们进入第 2 章：为什么多电子方程不能直接解？
